## About

My PIE-folio is a responsive, dark-and-gold portfolio built with React and Vite. It brings together engineering work, community leadership, creative mathematics, and an art-deco-inspired visual resume.

## Highlights

| Area | What you can explore |
| --- | --- |
| **Hero** | Animated geometric portrait, a live age counter, and decimal, binary, and hexadecimal views |
| **About** | Education, training, projects, leadership, skills, interests, and languages |
| **Resume** | Themed web resume plus a separate download of the standard PDF |
| **Achievements** | Milestone counters and an animated Fibonacci-to-golden-spiral illustration |
| **Projects** | Interactive project cards with animated mathematical previews and detail dialogs |
| **Math Lab** | Interactive sine/FFT visualization and golden-angle sunflower |
| **Contact** | Email, GitHub, and LinkedIn links |
| **Background effects** | A π-digit path and a subtle pointer trail on supported desktop devices |

## Built with

- React 18
- Vite 8
- JavaScript, CSS, SVG, and Canvas 2D
- GitHub Actions and GitHub Pages

## Run locally

Install **Node.js 20.19+ or 22.12+**.

```bash
npm ci
npm run dev
```

Vite prints the local URL after the development server starts. To create and preview a production build:

```bash
npm run build
npm run preview
```

`node_modules/` contains the installed React and Vite dependencies. It is generated by `npm ci`, ignored by Git, and should not be committed. `dist/` is generated by the production build and is also ignored.

## Motion and animation

- The **Motion** control in the navigation enables or disables the site’s animations. The choice is saved in browser storage.
- The site follows `prefers-reduced-motion` by default. If that preference is active, use **Enable motion** to opt into the effects.
- Reveal effects begin as their section enters the viewport. Project waves and the Math Lab canvas pause when scrolled away, then resume when visible.
- The geometric portrait reveals automatically when it enters view. The sunflower and signal visualizations are interactive; select a Math Lab tab to view each one.
- The pointer trail is limited to devices with a fine pointer. Browsers without `IntersectionObserver` use an immediate-reveal fallback.

The project targets current evergreen browsers. It uses standard CSS, SVG, and Canvas 2D features; exact rendering and frame rate can vary by browser and device.

## Update portfolio content

- **Portrait:** replace `assets/geo_profile.jpeg` with the profile image used by the geometric reveal.
- **Favicon:** replace `assets/icon.png`.
- **Resume download:** replace `assets/resume.pdf`. The themed web resume is authored separately in `src/App.jsx`, so update its content there as well.
- **Page content and interactions:** edit `src/App.jsx`.
- **Theme, layout, and responsive styles:** edit `src/styles.css`.
- **Dependencies and commands:** see `package.json`; use `npm ci` to install from the lockfile.

The `assets/` directory is Vite’s public asset directory. Reference public files by their filename through the existing `asset()` helper so the paths work both locally and on GitHub Pages.

## Deploy to GitHub Pages

The workflow at `.github/workflows/pages.yml` builds and deploys the site when code is pushed to `main`. It can also be started manually from the repository’s **Actions** tab.

1. In GitHub, open **Settings → Pages**.
2. Set the publishing source to **GitHub Actions**.
3. Push changes to `main` or run the deployment workflow manually.

The GitHub Actions build uses the `/Myportfolio/` base path; local development uses `/`. The deployed URL is `https://indra4626.github.io/Myportfolio/`.
